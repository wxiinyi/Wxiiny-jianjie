# Wxiiny-jianjie

王馨怡个人网站，使用纯 HTML、CSS 和 JavaScript 构建，并通过 GitHub Pages 发布。

五段原始视频保存在 `media-v1` GitHub Release 中，页面直接引用 Release 资源，以保留原始分辨率与画质。
原始字节数与 SHA-256 校验值记录在 `media-manifest.json`。

## 本地预览

直接打开 `index.html`，或在此目录启动任意静态文件服务器。

## 发布

推送到 `main` 分支后，GitHub Actions 会自动部署当前目录到 GitHub Pages。
